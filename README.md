# Grupitorarara

Proyecto académico cuyo objetivo es aprender a operar el mercado financiero. La idea es aplicar ese conocimiento durante el semestre y, con lo aprendido, comprar una pizza al final del semestre.

## Objetivo

- Aprender conceptos y herramientas para operar el mercado.
- Practicar con datos y análisis reales (o simulados) a lo largo del curso.
- Cerrar el semestre "cobrando" el aprendizaje: comprar una pizza con las ganancias (o al menos con la excusa) obtenidas gracias a lo aprendido.

## Stack

- Python gestionado con [uv](https://docs.astral.sh/uv/)
- [Streamlit](https://streamlit.io/) para la interfaz

## Cómo correrlo

```bash
uv run streamlit run app.py
```
